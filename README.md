# Zalternations Online 🚀

> Modern, interactive, cyberpunk & retro pixel-art aesthetic creative agency & portfolio website.

Built with **Next.js 14**, **React 18**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features

- 🎮 **Interactive Flappy Hero Game**: An arcade mini-game playable directly inside the hero section with high score tracking, retro sound effects, and smooth physics.
- 🎨 **Retro Pixel & Cyberpunk Aesthetic**: High-contrast dark theme, neon accents, glowing CRT effects, and custom pixel-art motifs.
- 💼 **Featured Showcase & Work**: Interactive portfolio project modals, tech stack badges, and live demo links.
- ⚡ **Capabilities & Services**: Complete breakdown of creative development, 3D graphics, game dev, and branding services.
- 📬 **Interactive Modals**: Seamless contact form and video showreel viewer.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

---

## 🛠 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **3D / Canvas**: [Three.js](https://threejs.org/) & Web Audio API
- **Language**: TypeScript

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/SunshineZone/zalternationsonline.git
cd zalternationsonline
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
